# CLIP

## Kurulum

1. GitHub Releases sayfasından sisteminize uygun hazır paketi (`CLIP-Windows.zip` veya `CLIP-macOS.zip`) indirin ve klasöre çıkartın.
2. Başlatıcıyı tek tıkla çalıştırın (tüm kütüphaneleri otomatik kurar ve servisi hemen başlatır):
   - Windows: `CLIP.bat`
   - Mac: `CLIP.app` veya `CLIP.command`
3. Tarayıcınızda (Chrome / Brave / Edge) eklentiler sayfasına gidin (`chrome://extensions` veya `brave://extensions`).
4. Sağ üstten "Geliştirici Modu"nu açın, "Paketlenmemiş Öğe Yükle" butonuna tıklayıp bu klasörü seçin.

## Nasıl Kullanılır?

Link kopyalamak yerine videoyu doğrudan panonuza dosya olarak kopyalar:

- YouTube Shorts, TikTok, Instagram Reels veya X'te videonun yanındaki CLIP simgesine tıklayın.
- YouTube yatay videolarda Beğen butonunun yanındaki "Klip Al" butonuna tıklayıp süreyi belirleyin.
- WhatsApp veya Discord'a geçip Ctrl+V (Mac için Cmd+V) yapın; video anında yapışır.

Windows'ta sağ alttaki sistem tepsisinden, Mac'te üst menü çubuğundan uygulamayı istediğiniz zaman tek tıkla açıp kapatabilirsiniz.
